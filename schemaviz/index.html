schemaviz

Draw a database schema as an interactive page, and see exactly what a migration changed. Point it at a repository, a SQL dump, a dbt project or a live database.

Samples

What a migration changed A made-up recipe app, before and after. A renamed table, a retyped column, a new table and a dropped one, marked in place. schemaviz diff A repository, scanned dbt Labs' open-source jaffle_shop, drawn from its folder with real warehouse types. schemaviz scan jaffle_shop_duckdb

Try it

brew install phin-tech/tap/schemaviz

schemaviz scan ./your-repo --out schema.dbml
schemaviz open schema.dbml

Compare two points in history, with a revision picker in the page:

schemaviz open docs/schema.dbml --from v1.4 --to HEAD
Source and docs. The jaffle_shop schema comes from dbt-labs/jaffle_shop_duckdb. The recipe app is invented for this page.
